КОЛЯГРАМ v7.0 — ДРУЗЬЯ ОНЛАЙН

Подключён реальный Supabase проект.

Работает:
• анонимный вход без почты;
• вход по закрытому коду KOLYA2026;
• общий список пользователей между телефонами;
• общий чат;
• личные чаты;
• сообщения в реальном времени;
• фото и голосовые через Supabase Storage;
• общие аватарки: сменил фото — друзья видят его;
• звук входящего сообщения;
• голосовой плеер v6.6 с паузой, шкалой и 1×/2×/3×.

Перед тестом:
1. В Supabase должен быть включён Allow anonymous sign-ins.
2. Выполни setup.sql из этой сборки в SQL Editor (если предыдущий SQL уже выполнен, этот можно запустить поверх).
3. Загрузи все файлы в GitHub с заменой.
4. Проверяй на двух разных телефонах с кодом KOLYA2026.

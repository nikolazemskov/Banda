КОЛЯГРАМ v8.5

Ключевая переделка чата:
• при новом сообщении старая переписка НЕ перерисовывается;
• новое сообщение добавляется одной строкой в конец DOM;
• фото и аватарки старых сообщений не перезагружаются и не должны моргать;
• галочки обновляются точечно внутри конкретного сообщения;
• резервный polling раз в 1.8 сек теперь безопасен, потому что не пересобирает чат;
• polling сам обнаруживает новое входящее и запускает звук, если Realtime на iPhone уснул;
• Dota-звук переведён на Web Audio API и должен играть поверх фоновой музыки;
• после своей отправки чат принудительно остаётся в самом низу;
• прокручивается только контейнер сообщений, а не вся страница.

SQL менять не нужно.

БАНДА PWA v2 — TIFFANY

УЖЕ ЕСТЬ
• закрытый вход по коду;
• общий чат;
• личные чаты;
• крупный светлый Tiffany-интерфейс;
• фото из галереи одной кнопкой;
• голосовые;
• профиль;
• установка на главный экран iPhone;
• локальный демо-режим без сервера;
• готовая схема Supabase для реального общения между телефонами.

БЫСТРАЯ ПРОВЕРКА
1. Опубликуй файлы на GitHub Pages.
2. Открой ссылку в Safari.
3. Код: BANDA2026.
4. Введи имя.
5. Добавь на экран «Домой».

КАК ВКЛЮЧИТЬ РЕАЛЬНЫЙ ОБЩИЙ ЧАТ
1. Создай бесплатный проект на supabase.com.
2. Authentication → Providers → Anonymous Sign-Ins → включить.
3. SQL Editor → вставь и запусти setup.sql.
4. Project Settings → API:
   - скопируй Project URL;
   - скопируй anon/public key.
5. Открой config.js и вставь эти два значения.
6. Перезалей config.js на GitHub Pages.
7. Отправь друзьям одну и ту же ссылку и код.

ВАЖНО
• В демо-режиме сообщения остаются только на текущем устройстве.
• Фото/голосовые в демо используют временные локальные URL и после перезапуска могут исчезнуть.
• Для настоящего чата всем нужен один опубликованный сайт, подключённый к одному Supabase-проекту.
• Push-уведомления пока не включены. Их лучше добавить после проверки базового чата.

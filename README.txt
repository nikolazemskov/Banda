КОЛЯГРАМ v6.6

Ключевое исправление:
Предыдущие версии пытались улучшать HTML <audio>, но реальные голосовые в КОЛЯГРАМ создавались кнопкой data-audio и каждый клик создавал новый Audio().
Теперь переделан непосредственно рендер голосового сообщения.

• Play / Pause без дублей.
• Один Audio-объект на одно сообщение.
• Одновременно играет только одно голосовое.
• Реальная движущаяся шкала.
• Перемотка.
• Текущее время / полная длительность.
• Скорость 1× / 2× / 3×.
• После окончания возврат в начало.

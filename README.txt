КОЛЯГРАМ v6.3

Новое:
• во время записи голосового появляется красная панель и таймер;
• красный крестик отменяет текущую запись;
• короткий звук при старте записи;
• короткий звук при завершении записи;
• добавлен локальный звук входящего сообщения «пердеж»;
• сохранены изменения v6.2: аватарка, фирменная шапка, эмодзи и PWA.

Примечание iPhone:
Safari/PWA разрешает воспроизведение звуков после взаимодействия пользователя со страницей.
Для фоновых уведомлений при полностью закрытом приложении потребуется отдельная настройка Web Push.

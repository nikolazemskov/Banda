ВАЖНО ПЕРЕД ЗАПУСКОМ ДЛЯ ДРУЗЕЙ:
Эта сборка готовит интерфейс. Для настоящего общего мессенджера между разными телефонами
нужен подключённый сервер/база данных (например Supabase) и настройка правил доступа.
Не раздавайте друзьям как полноценный чат, пока не проверена синхронизация сообщений
между двумя разными устройствами.
